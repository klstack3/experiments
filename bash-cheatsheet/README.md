# Bash Navigation & Manipulation Cheatsheet

A comprehensive, interactive cheat sheet for Bash navigation and file manipulation commands with a modern, terminal-inspired design.

## 🎯 Features

- **Interactive Command Reference**: Comprehensive collection of bash commands organized by category
- **Modern Terminal Design**: Dark theme with green accent colors and scanline effects
- **Copy-to-Clipboard**: Click any command to copy it to your clipboard
- **Responsive Layout**: Works on desktop and mobile devices
- **Terminal Aesthetics**: Retro CRT monitor styling with custom fonts

## 📋 Command Categories

- **Navigation Commands**: cd, pwd, ls, find, locate
- **File & Directory Operations**: mkdir, rmdir, rm, cp, mv, touch
- **File Content & Viewing**: cat, less, more, head, tail, grep
- **File Permissions & Ownership**: chmod, chown, chgrp
- **System Information**: df, du, ps, top, uname
- **Network & Connectivity**: ping, curl, wget, ssh
- **Archive & Compression**: tar, zip, unzip, gzip
- **Text Processing**: sort, uniq, wc, cut, awk, sed

## 🚀 Usage

Simply open `index.html` in your web browser to access the interactive cheat sheet.

## 🎨 Design Features

- Custom fonts (JetBrains Mono & Syne)
- Terminal-inspired color scheme
- Hover effects and animations
- CRT scanline overlay
- Responsive grid layout
- Click-to-copy functionality
